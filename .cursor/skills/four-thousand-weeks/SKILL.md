## When to Apply

- Overwhelm, burnout, or "never enough time" despite productivity systems
- Efficiency trap: doing more creates more to do; convenience fills freed time
- Procrastination as **emotional avoidance** of finitude (not laziness)
- Distraction, attention drift, "watermelon problem"
- Guilt about rest, leisure, or "unproductive" time
- Impatience spiral; rushing; deferring satisfaction to a future that never arrives
- Illusion of **owning** or **controlling** time
- Existential time anxiety; pressure to "make life count" at cosmic scale
- User mentions 四千周, finitude, 拥抱限度, 固定时间产出, pay yourself first, etc.

**Not primary**: strategic interdependence with others' choices → [thinking-strategically](../thinking-strategically/SKILL.md); important option choice without time/finitude theme → [wrap-decision-making](../wrap-decision-making/SKILL.md).

**Vs WRAP / Thinking Strategically**: Four Thousand Weeks = **relationship with finite time & meaning**; not payoff matrices or option widening.

## Pre-Flight

### 1. Trap Diagnosis Gate

Identify dominant pattern (pick **one primary**):

| Trap | Signal |
|------|--------|
| **Efficiency trap** | More systems/hacks → more tasks; never "caught up" |
| **Avoidance procrastination** | Paralysis from refusing to choose what to drop |
| **Distraction** | Knows what matters; attention goes elsewhere |
| **Control illusion** | Planning/busyness to escape uncertainty & limits |
| **Rest guilt** | Leisure only justified as recovery or self-improvement |
| **Impatience spiral** | Speeding up to feel in control; world still too slow |
| **Cosmic pressure** | Life must be "significant" or leave a mark |
| **Time sovereignty loneliness** | Freedom of schedule vs loss of shared rhythm |

Unclear → ask **one** question (which feels most stuck: doing too much / not starting / distracted / can't rest / rushing / meaning pressure?).

### 2. Information Gate

Critical unknowns (actual constraints, health, dependents, non-negotiable deadlines, values about what matters) → Gate only; no fabricated life advice.

### 3. Stance Check

Label user's implicit stance: **More-time seeker** (fix time scarcity) · **Control seeker** (master the schedule) · **Significance seeker** (life must matter cosmically) · **Already questioning productivity** → calibrate tone (validate pain; don't preach finitude to someone in acute crisis without care).

## Workflow

Cap **2–3 concepts/tools** (default **2**). Label: `applied` / `ruled out` / `pending data`.

### Step 1 — Name the finite frame

One line: ~4000 weeks; the issue is not scarcity alone but **problematic beliefs about time** + unwillingness to choose what to sacrifice.

### Step 2 — Select concepts/tools

From concept IDs, match trap → concepts. Prefer pairing **one diagnostic concept** + **one practical tool** from `ten-tools` (or a numbered tool ID).

Examples:
- Efficiency trap → `efficiency-trap` + `fixed-schedule-productivity`
- Avoidance procrastination → `better-procrastinator` + `ignore-actively`
- Distraction → `watermelon-problem` / `intimate-interrupter` + `one-thing-at-a-time`
- Rest guilt → `rediscover-rest` + `boredom-presence`
- Impatience → `impatience-spiral` + `staying-on-bus`
- Control illusion → `never-own-time` + `staying-on-bus` (stop when time is up)
- Cosmic pressure → `cosmic-insignificance` + `focus-completed`
- Loneliness of schedule freedom → `digital-nomad-loneliness` + `instant-generosity`

### Step 3 — Apply (per concept)

From the user-language reference, extract only selected sections:

- **Reframe**: what the trap really is (1–2 lines)
- **Implication** for user's situation
- **Conditionality** · **Falsifier** — **required**; copy from reference when present
- Optional: book anchor (verbatim)
- **One concrete next move** (behavioral, small, today)

If reference lacks **Conditionality** or **Falsifier** for a selected entry → label that field `pending data` for that concept; **do not infer, synthesize, or fabricate** the missing boundary or life advice.

No manifesto dump. Do not promise "balance" or "having it all."

### Step 4 — Finitude check

Ask implicitly in synthesis:
- What is user **choosing not to do**?
- What sacrifice makes the chosen focus real?
- Is the advice secretly another efficiency hack? → reject it.

### Step 5 — Synthesize

Conditional reframe · 1–2 tools · one next move · permission to be finite.

Final choices stay with user.

## Constraints

1. **Never** imply user can finish everything with better methods.
2. Distinguish **strategic procrastination** (wise omission) from **avoidance procrastination** (paralysis).
3. Rest and play are valid **ends**, not only recovery for work.
4. One clarifying question per turn (≤3 if Gate).
5. Multi-turn → **Delta** only.
6. Acute mental health crisis → compassion first; skill is not therapy.

## Core Chain (quick reference)

1. **Face truth**: ~4000 weeks; accept finitude
2. **Stop escaping**: efficiency, distraction, busy planning — all avoid limits
3. **Release control**: you don't own time; you are time
4. **Embrace limits**: sacrifice gives choice meaning
5. **Be here**: stop treating life as prelude to a better future
6. **Beyond hope**: world is uncertain; do the next necessary thing
