## 核心理念

### 战略思维本质

**来源/背景**：博弈论系统化研究「战略相互依存」——你的结果取决于他人有目的的选择，而对手也在同样思考。全书贯穿商业竞争、政治博弈、家庭管教与国际关系。

**定义**：在互动决策中胜过对手的艺术；同时必须站在对手立场推理其最优反应。

**公式/图示**：

```
博弈三要素：参与者 Players → 行动 Moves → 收益 Payoffs
战略相互依存：U_i = f(a_i, a_{-i})  （你的收益取决于所有人行动）
```

**适用场景**：任何「你的最佳选择取决于他人会怎么做」的情境——定价、谈判、投票、军备、 parenting。

**不适用场景**：纯个人偏好决策（无互动 payoff）；纯随机环境（无对手策略）；信息完全且无策略空间的机械优化。

**经典案例/反例**：
- 案例：两家相邻加油站互相盯价——每家定价都考虑对方反应
- 反例：独自决定今天穿什么——无战略相互依存，不需要博弈论

**常见误区**：
- 只考虑自己的最优，不模拟对手反应
- 把「聪明」等同于「更复杂」——简单占优策略往往足够

**书中语**：「战略思维是在互动决策中胜过对手的艺术，同时深知对手也在做同样的事。」

### 向前展望向后推理 Rule 1

**来源/背景**：全书第一法则，适用于所有**顺序行动**博弈；与决策树不同，博弈树必须多视角（己方 + 对手）。

**定义**：预测初始决策最终将导向何种结果，据此倒推当前最优选择（逆向归纳 / backward induction）。

**公式/图示**：

```
博弈树示例（简化）：

        [你: 进/退]
       /          \
  [对手: 战/和]   [终局收益]
   /      \
[终局]  [终局]

步骤：从叶节点 → 每层选最佳回应 → 回推至根节点
```

**适用场景**：下棋、序贯谈判报价、产品发布节奏、法律诉讼策略、任何「先动/后动」链。

**不适用场景**：严格同时行动且无法观察对方（用收益矩阵+均衡）；信息集不完整且无法排序时需谨慎。

**经典案例/反例**：
- 案例：围棋终局——从终局倒推当前落子
- 反例：在不了解对手后续分支时「向后推理」——树结构错误则推理无效

**常见误区**：
- 只向前看一步，未推到博弈终点
- 在博弈树中只标注己方最优，未给对手节点标注**其**最优

### 混合动机

**来源/背景**：全书核心洞察——现实博弈极少是纯零和或纯合作。

**定义**：参与者之间既有利益冲突，又有共同利益；例如劳资谈判中工资对立，但双方都怕罢工。

**公式/图示**：

```
纯冲突（零和）：  u_1 + u_2 = 0
纯合作：          目标一致，协调即可
混合动机：        部分维度冲突 + 部分维度一致（常态）
```

**适用场景**：大多数商业伙伴关系、国际外交、团队内部资源分配、监管与被监管关系。

**不适用场景**：严格体育零和计分（一方得分即对方失分）；完全aligned的小团队无资源约束。

**经典案例/反例**：
- 案例：OPEC 成员国——既竞争市场份额，又共同希望油价高
- 反例：将劳资谈判建模为纯零和——忽略「避免双输」的合作面

**常见误区**：
- 非友即敌的二元框架
- 忽视「可合作维度」导致错过 Pareto 改进

---

### 囚徒困境

**来源/背景**：全书最核心悖论；个人理性 → 集体非理性；后续重复博弈、承诺、惩罚皆为此结构服务。

**定义**：每位参与者都有**占优策略**背叛/竞争，但双方合作时总收益更高；均衡劣于合作结果。

**公式/图示**：

```
        对手合作    对手背叛
你合作   (3,3)      (0,5)
你背叛   (5,0)      (1,1)

→ 双方背叛 (1,1) 为纳什均衡，但 (3,3) 合作 Pareto 更优
```

**适用场景**：价格战、公地悲剧、军备竞赛、团队搭便车、一次性交易中的质量偷工减料。

**不适用场景**：有有效重复互动+检测+惩罚的一次性之外关系；存在外部 enforceable 合同；非 PD 结构的协调博弈。

**经典案例/反例**：
- 案例：两家寡头价格战——各自降价是占优，结果利润双杀
- 反例：重复采购+可观测质量+断供惩罚——PD 的一次性逻辑失效

**常见误区**：
- 认为「理性人应该合作」——在**一次性** PD 中背叛是理性均衡
- 把任何冲突都称为囚徒困境——需验证占优背叛结构

**书中语**：「每个参与者都按自身的占优策略行动，结果反而使双方都陷入比合作更差的境地。」

## 基础工具

### 占优策略 Rule 2

**来源/背景**：行动规则 2——分析同时行动博弈的第一步。

**定义**：无论对手采取什么策略，该策略对你的收益**始终**高于你的其他所有策略。

**公式/图示**：

```
收益矩阵行比较法：
若 Row A 每个元素 > Row B 对应元素 → A 行是占优策略

行动规则：有占优策略 → 执行；对手有占优策略 → 预期其执行
```

**适用场景**：明显「无论如何都应选 X」的决策；先扫矩阵再深入均衡。

**不适用场景**：无占优策略（大多数复杂博弈）；需混合策略的对抗。

**经典案例/反例**：
- 案例：某些拍卖中「诚实报价」在第二价格密封拍卖中是占优策略（Vickrey）
- 反例：将「比对手更好」误认为占优——占优是**对自己其他策略**而言

**常见误区**：
- 占优 ≠ 优于对手策略
- 占优 ≠ min-max（最坏情况最优）——只需对每个对手策略都更好

---

### 被支配策略 Rule 3

**来源/背景**：当无占优策略时，通过剔除缩小博弈规模。

**定义**：无论对手如何行动，策略 D 始终劣于你的策略 S；理性人不会选 D。

**公式/图示**：

```
迭代剔除：
1. 找被支配策略 → 删除
2. 在剩余博弈中重复
3. 若出现新占优策略 → Rule 2
```

**适用场景**：至少一方有 ≥3 个策略选项；矩阵较大需化简。

**不适用场景**：策略连续或近似无差异；所有策略都不被严格支配。

**经典案例/反例**：
- 案例：三策略投票博弈中，「投最差候选人」可能被支配而剔除
- 反例：剔除后假设对手仍可能用被支配策略——违背理性假设

**常见误区**：
- 只剔除一轮就停止——应迭代至无法再剔
- 混淆「弱支配」与「严格支配」（本书强调严格劣）

### 纳什均衡 Rule 4

**来源/背景**：约翰·纳什；打破「我猜他在猜我……」的循环。

**定义**：策略组合中，每人策略都是对他人策略的**最佳回应**；无人愿单方面偏离。

**公式/图示**：

```
(a_1*, a_2*) 为纳什均衡 ⟺
∀i: u_i(a_i*, a_{-i}*) ≥ u_i(a_i, a_{-i}*)  ∀a_i

找法：标注每格中每人的最佳回应 → 双方都是最佳回应的格 = 均衡
```

**适用场景**：同时行动：定价、广告投入、技术选型、任何「互相猜测」的同时决策。

**不适用场景**：需序贯信息时应用博弈树；均衡过多需协调/refinement；完全合作无冲突。

**经典案例/反例**：
- 案例：囚徒困境 (背叛,背叛)；性别战中的两个均衡
- 反例：将非均衡策略组合当作稳定预测——未验证单方偏离动机

**常见误区**：
- 纳什均衡 ≠ 社会最优（PD 均衡即劣于合作）
- 唯一均衡假设——许多博弈有多个均衡

### 博弈树与逆向推理

**来源/背景**：顺序行动博弈的标准工具；与单决策树区别在必须双（多）视角。

**定义**：树状图表示决策顺序；从终局节点逆向归纳各节点最优选择。

**公式/图示**：见 [向前展望向后推理 Rule 1](#向前展望向后推理-rule-1) 树图。

**适用场景**：Stackelberg 领导-跟随、序贯进入、多轮谈判轮次。

**不适用场景**：同时行动且信息对称——用矩阵。

**经典案例/反例**：
- 案例：市场进入——在位者威胁降价 → 进入者逆向推理是否仍进入
- 反例：忽略信息集（不完全信息）——需子博弈完美均衡 refinement

**常见误区**：
- 用决策树（单人）代替博弈树（多人）
- 未在对手节点标注**对手**最优而非己方希望

---

### 收益矩阵与最佳回应

**来源/背景**：同时行动博弈的可视化基础。

**定义**：**收益矩阵**列出策略组合与 payoff；**最佳回应**是给定对手策略时你的最高收益策略。

**公式/图示**：

```
        对手: L      对手: R
你: U   (a,b)      (c,d)
你: D   (e,f)      (g,h)

若对手选 L：比较 U 与 D 中你的收益 → 较高者为 BR
```

**适用场景**：双变量策略、快速视觉比较占优/均衡。

**不适用场景**：策略空间连续或高维——需简化或数值方法。

**经典案例/反例**：
- 案例：「覆盖法」判断行占优——一行数字全大于另一行
- 反例：三人及以上需多维表格或简化

**常见误区**：
- 混淆 payoff 绝对值与相对排序
- 未区分行玩家与列玩家角色

## 核心策略

### 重复博弈与以牙还牙

**来源/背景**：解决 PD 的核心路径；Axelrod 计算机锦标赛验证 Tit-for-Tat。

**定义**：**重复博弈**——关系持续使「未来损失」约束当前背叛；**以牙还牙**——清晰、友善、可激怒、宽容四原则。

**公式/图示**：

```
合作条件（直觉）：
未来合作收益折现和 > 一次背叛收益

Tit-for-Tat 四原则：
Clarity 清晰 | Niceness 不先背叛 | Provocability 遇背叛即反击 | Forgivingness 不长期记仇

透明度递增定律：合作→透明维度；竞争→隐蔽维度
```

**适用场景**：长期供应商、重复客户、团队持续协作、国际关系（无确定终止日）。

**不适用场景**：**有限次**重复且双方知终止日——逆向推理导致末轮背叛、合作 unravel；检测作弊极难；惩罚不可信。

**经典案例/反例**：
- 案例：Axelrod 锦标赛中 TFT 表现优异
- 反例：已知最后一轮的重复博弈——末轮无惩罚威胁，合作从最后一轮向前崩溃

**常见误区**：
- 认为重复一定促成合作——需检测+惩罚+不确定期限
- TFT 在任何环境最优——噪声环境下可能过度报复

**书中语**：「如果不存在明天，今天的承诺就无法反悔。」

### 战略行动

**来源/背景**：改变他人预期以改变其行为；先发制人性质。

**定义**：
- **无条件行动**：单方面锁定选择，变同时序为顺序，获先行优势
- **威胁**：不按你意行事则惩罚（改变回应规则）
- **承诺**：按你意行事则奖励（改变回应规则）

**公式/图示**：

```
威胁/承诺 vs 警告/保证：

警告/保证 = 告知你本来就会做的回应（信息）
威胁/承诺 = 刻意偏离未来自然最优，以操纵对手（需可信度）

关键：威胁/承诺要求未来「违背自身利益」→ 可信度问题
```

**适用场景**：谈判前置承诺、市场进入威慑、政策「说到做到」、合同设计。

**不适用场景**：空口威胁无成本——不可信；对手无法观察或验证。

**经典案例/反例**：
- 案例：Burn bridges 破釜沉舟使撤退不可行
- 反例：「如果你涨价我就自杀式降价」——若事后违背更优，威胁不可信

**常见误区**：
- 把警告当威胁——未改变 payoff 结构
- 威胁过极端——理性对手知你不会执行

---

### 可信承诺

**来源/背景**：全书「八正道」；承诺不可信则战略行动失效。

**定义**：通过改变收益、声誉、合同等使**遵循承诺符合自身利益**或**违背成本极高**。

**公式/图示** — **八正道**：

| 途径 | 机制 |
|------|------|
| 破釜沉舟 | 消除退路 |
| 控制权外置 | 委托第三方执行 |
| 声誉资本 | 违约损失 > 单次收益 |
| 合同+保证金 | 经济惩罚 |
| 小步走 | 大承诺拆步兑现 |
| 团队决策 | 集体不可逆 |
| 标准操作程序 | 嵌入流程 |
| 没有明天 | 最后关头不可反悔 |

**适用场景**：投资不可逆、并购交割、政策 credibility、军事 alliance。

**不适用场景**：低成本反悔；声誉无价值（一次性匿名互动）。

**经典案例/反例**：
- 案例：Cortés 烧毁船只
- 反例：无 enforcement 的国际条约——缺乏可信惩罚

**常见误区**：
- 口头承诺等于可信承诺
- 忽视「威胁→警告」转化：使执行成为自身最优

### 混合策略

**来源/背景**：可被预测的模式会被利用；需真随机化。

**定义**：以一定概率在多个行动间随机选择，使对手**无法预测**单次行动；最优混合比例使对手对各行动**无差异**。

**公式/图示**：

```
混合策略 σ = (p_1, p_2, ...), Σp_i = 1

最优条件：对手在应对你的混合策略时，各纯策略收益相等（无差异）

❌ 固定交替模式（可预测）
✅ 真随机（不可预测）
```

**适用场景**：网球发球方向、促销时机、税务审计频率、军事突袭、任何「一方要重合/一方要避免重合」。

**不适用场景**：有占优纯策略；合作协调无冲突；信息价值来自可预测性。

**经典案例/反例**：
- 案例：点球大战随机方向
- 反例：按固定 50-50 交替——对手可识别模式

**常见误区**：
- 混合 = 随意——需计算无差异概率
- 认为随机 = 非理性——混合策略可以是均衡

## 应用场景

### 边缘政策

**来源/背景**：托马斯·谢林；核威慑与危机外交的经典框架。

**定义**：刻意创造**不完全受控**的可识别风险，使局势「轻微失控」以迫使对手让步——非确定性威胁。

**公式/图示**：

```
Brinkmanship ≠ 确定性极端威胁（常不可信）
         = 可控滑坡：风险逐步增大，双方沿斜坡下滑

成功要素：风险可调 | 分步升级 | 部分失控机制 | 清晰退出路径
```

**适用场景**：危机谈判、劳资极限施压、监管「逐步收紧」、商业 deadline 压力。

**不适用场景**：风险不可控且己方也无法承受；对手无退路；一次性 cheap talk。

**经典案例/反例**：
- 案例：古巴导弹危机——可控风险与沟通
- 反例：「不服就核战争」——过于极端不可信

**常见误区**：
- 边缘政策 = 虚张声势——需真实风险机制
- 风险过大——己方也陷入不可接受境地

**书中语**（谢林）：「刻意创造一种可识别的、不完全受你控制的风险。」

### 合作与协调

**来源/背景**：合作解决背叛；协调解决多均衡选择。

**定义**：
- **合作**：克服 PD 式背叛诱惑 → 重复+惩罚
- **协调**：多均衡中聚焦同一均衡 → **聚焦点 Focal Point**、惯例、沟通

**公式/图示**：

```
协调博弈（性别战）：多个纳什均衡，需选同一个
聚焦点：无沟通时基于文化/惯例/常识的「显而易见」选择

手风琴效应：小步合理 → 累积对所有人不利（投票陷阱）
→ 用 Rule 1 在第一步预见终点
```

**适用场景**：行业标准、交通规则、国际协议、技术格式战争、会议时间约定。

**不适用场景**：纯 PD 无协调均衡——需先解决合作再协调。

**经典案例/反例**：
- 案例：「在纽约见面」——默认时代广场为聚焦点
- 反例：无共同文化的聚焦点——可能协调失败

**常见误区**：
- 混淆合作问题与协调问题——工具不同
- 忽视手风琴效应的累积陷阱

### 投票策略

**来源/背景**：民主理想 vs 战略操纵；阿罗不可能定理。

**定义**：个人偏好加总为集体选择时的战略问题——循环、议程操纵、策略性投票。

**公式/图示**：

```
投票循环：A ≻ B ≻ C ≻ A → 无稳定胜者，顺序决定结果

中位数选民定理（一维）：候选人向中位数靠拢
多维：中位数消失 → 操纵空间增大

策略性投票：投「有胜算者」而非「最爱者」
```

**适用场景**：董事会、股东投票、政治选举分析、任何议程设置权。

**不适用场景**：二人决策； sincere voting 无激励偏离的 special cases。

**经典案例/反例**：
- 案例：议程操纵改变 Borda/Copeland 类结果
- 反例：「我的票决定不了」——单次影响小但手风琴累积

**常见误区**：
- 存在「完美」投票制度（阿罗否定）
- 真诚投票总是最优

**书中语**：「投票中的力量可以是弱点，弱点也可以是力量。」

### 谈判

**来源/背景**：分蛋糕问题；规则制定权在正式谈判前已开始。

**定义**：分割可分配 surplus；**耐心**与**外部选项**决定力量对比。

**公式/图示**：

```
四大要素：
1. 耐心 / 等待成本 — 更能熬者获更大份额
2. 「这伤你比伤我重」— 改变 outside option
3. 规则制定权 — 框架优势
4. 多议题打包 — 交换偏好强度

无限期谈判直觉：极限份额 ∝ 相对耐心（Rubinstein 型）
50:50 常为对称耐心下的均衡
```

**适用场景**：薪资、并购、联盟、国际条约、任何 bilateral/multilateral 分配。

**不适用场景**：完全竞争市场定价（非双边谈判）；无 surplus 可分。

**经典案例/反例**：
- 案例：先报价者锚定框架
- 反例：忽视 outside option——误判 BATNA

**常见误区**：
- 谈判只关于「公平」——更是耐心与承诺博弈
- 单次报价不考后续轮次——序贯结构

### 激励设计

**来源/背景**：机制设计；使理性自利导向社会目标。

**定义**：锦标赛、拍卖、惩罚、产权、竞争等制度设计。

**公式/图示**：

```
核心主题：
· 绩效-激励权衡（锦标赛、相对排名）
· 外部性内部化（JV、利润分享）
· Vickrey 拍卖：第二价格 → 真实报价为占优策略
· 赢家诅咒：共同价值拍卖 → 中标者常过度乐观 → 向下调整报价
· 惩罚简洁性：潜在作弊者能准确预测后果
```

**适用场景**：员工晋升、采购拍卖、合资治理、遗产安排、监管处罚。

**不适用场景**：努力完全可观测且可契约化——简单合同即可。

**经典案例/反例**：
- 案例：Vickrey 拍卖激励诚实出价
- 反例：油田共同价值拍卖——赢家诅咒导致过度支付

**常见误区**：
- 绝对绩效 vs 相对绩效混淆
- 忽视多主体连坐惩罚伤及无辜

## 与 WRAP / Model Thinker 边界

| 框架 | 核心问题 |
|------|----------|
| **Thinking Strategically** | 互动 payoff、对手建模、均衡与承诺 |

互动决策优先本 skill；纯个人选择用 WRAP；系统涌现/分布/传播用 Model Thinker。
