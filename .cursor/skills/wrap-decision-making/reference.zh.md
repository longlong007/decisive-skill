# WRAP 决策框架（中文）

基于奇普·希思与丹·希思《决断力：如何在生活与工作中做出更好的选择》。与英文版 [SKILL.md](SKILL.md) 结构对应，使用中文版书籍术语。

## 何时启用

满足以下任一条件时，以 WRAP 作为**唯一主框架**（不与其他决策模型叠加）：

- 工作/职业/生活中的**较重要**决定
- 同时出现多种决策障碍：思维狭隘、证实倾向、短期情绪、过度自信
- 用户明确提到 WRAP、决断力、Decisive、拓宽选择、现实检验、事前验尸、绊网

**不适用**：事实缺失且应先做最小验证行动；纯可逆小选择（优先可逆性/小实验框架）。

## 四大因素，阻止你有效决策

先诊断当前决策被哪种障碍主导——WRAP 四步一一对应：

| 障碍 | 表现 | 对应步骤 |
|------|------|----------|
| 思维狭隘 | 只在「做 vs 不做」间选，忽视第三路 | W |
| 证实倾向 | 只搜集支持已有直觉的信息 | R |
| 短期情绪 | 被当下焦虑/兴奋驱动，忽视长期 | A |
| 过度自信 | 以为能预测未来，未做准备 | P |

## WRAP 流程

按 W → R → A → P 顺序执行。每步标注：`已使用` / `现有信息已满足` / `不适用已跳过`。

### W — 拓宽选择空间

**目标**：跳出 whether-or-not 式窄框定，同时考虑多个方向（兼顾两者，而非二选一）。

**必查基准方案**（至少保留适用的）：
- 不做（维持现状）
- 延后决定
- 组合方案
- 小规模尝试（尝试/ooch 前置）

**对应章节**：避免思维狭隘 · 多目标追踪 · 找到那个已帮你解决了问题的人

**技法**（选 1–2 个，详见 [techniques.zh.md](techniques.zh.md)）：
- 消失选项测试：「如果现有选项都不可用，你会怎么做？」
- 多目标追踪：并行考虑 2–3 个方向，而非逐个淘汰
- 爬梯子法：内部亮点 → 外部最优方法 → 跨领域类比
- 找已解决问题的人

**约束**：AI 新增选项必须标为「AI 提议，待用户确认」。

### R — 把假设放到现实中检验

**目标**：主动寻找**可能改变决定**的反证，而非强化已有偏好。

**对应章节**：考虑相反的情况 · 缩小，放大 · 尝试

**技法**（优先产出 1 个反证问题或最小实验）：
- 考虑相反的情况 / 魔鬼代言人
- 缩小（外视观点）：同类决策的基本比率是多少？
- 放大（内视观点纹理）：这个具体情境有哪些独特细节？
- 尝试（ooch）：用小实验代替预测——「与其预测，不如先知道」

**约束**：不虚构外部事实；证据不足时生成用户可执行的求证行动。

### A — 在做出决策前，留出一段距离来考虑

**目标**：降低短期情绪对判断的扭曲，回到核心价值观与长期优先级。

**对应章节**：克服短期情绪 · 尊重你的核心价值观

**仅在**短期情绪或外部压力可能遮蔽核心目标时触发**一个**距离问题：

- 你会建议最好的朋友怎么做？
- 你的继任者会怎么做？（安迪·格鲁夫旋转门测试）
- 10/10/10：10 分钟 / 10 个月 / 10 年后各会如何感受？
- 澄清核心价值观：这个决定真正要保护的是什么？

### P — 做好出错的准备

**目标**：承认不确定性，为坏结果和好结果都做准备，并设置重新评估触发器。

**对应章节**：「书档」未来 · 设置一个绊网

**必须落到可观察条件**，不能泛泛说「保持灵活」：

- **事前验尸**：假设 6–12 个月后已彻底失败，最可能原因？预警信号？
- **游行预演**：假设大超预期，需要提前准备什么？
- **绊网**：什么可观察信号会触发重新评估或停止？（停止条件 / 重开条件）

## 执行约束

1. 一次只问**一个**必要问题；核心引导最多 **3 个问题**。
2. WRAP 四步作为后台检查表，不要求用户填四张长表。
3. 可从用户已确认信息推导的步骤，**不得重复询问**。
4. 建议必须说明依赖的假设与不确定性；禁止保证结果。
5. 最终决定交还用户确认（接受 / 调整 / 拒绝）。

## WRAP 精简模式（时间不足时）

1. **W — 拓宽**：再增加一个选项，或找已解决问题的人。
2. **R — 现实检验**：向专家了解基本比率，或提一个反证问题。
3. **A — 留出距离**：哪个选项最符合核心价值观？
4. **P — 准备**：书档未来——花 1 小时想哪里会出错/会超预期，并为两种情况做准备。

## 输出模板

```markdown
## 决策陈述
[一句话描述正在做的决定]

## 障碍诊断
- [ ] 思维狭隘  [ ] 证实倾向  [ ] 短期情绪  [ ] 过度自信
[简要说明哪些障碍在起作用]

## WRAP 分析

### W — 拓宽选择空间
- 状态：[已使用 / 已满足 / 已跳过]
- 当前选项：[用户确认的选项]
- 新增选项（如有）：[标为 AI 提议，待确认]
- 基准方案：[不做 / 延后 / 组合 / 小实验]

### R — 把假设放到现实中检验
- 状态：[已使用 / 已满足 / 已跳过]
- 关键假设：[列出]
- 反证或实验：[一个可能改变决定的反证问题或最小实验]

### A — 留出距离来考虑
- 状态：[已使用 / 已满足 / 已跳过]
- 核心价值观 / 核心优先级：[长期真正要保护的目标]
- 距离视角：[10/10/10 或朋友/继任者视角的结论]

### P — 做好出错的准备
- 状态：[已使用 / 已满足 / 已跳过]
- 事前验尸：[失败情景与预警信号]
- 游行预演（如适用）：[超预期情景]
- 绊网：[可观察的停止/重开/重评触发器]

## 建议
**方向**：[明确建议]
**理由**（最多 3 条）：
1. ...
2. ...
3. ...

**关键取舍**：[选择了什么、放弃了什么]
**最大假设**：[若假设不成立，建议失效]
**不确定性**：[高/中/低 + 原因]

## 下一步行动
- **行动**：[48 小时内可执行的具体步骤]
- **成功标准**：[如何判断行动有效]
- **停止条件**：[何时放弃当前方向]
- **重开条件**：[何时重新考虑被否定的选项]
```

## 快速示例

**输入**：「我在考虑要不要跳槽到新公司，薪资高 30% 但行业不同。」

**W**：除跳槽/留任外，提出「先接副业试探新行业」「6 个月后再评估」→ 标为 AI 提议。
**R**：「新行业从业者在 3 年后仍留在该领域的比例？」「能否通过 2 周信息访谈验证文化匹配？」
**A**：10/10/10 — 10 个月后若后悔，最可能因为什么？
**P**：绊网 — 若 90 天内新岗位学习曲线导致核心项目交付延迟 >2 周，启动回评。
